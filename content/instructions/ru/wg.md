WireGuard выводится из эксплуатации. Используйте его, только если об этом попросил IT-отдел.

### Windows и macOS

1. Установите **WireGuard**: <https://www.wireguard.com/install/> (macOS — из App Store).
2. Скачайте свой файл `.conf` выше.
3. В WireGuard: **Import tunnel(s) from file** → выберите файл → **Activate**.

### iPhone, iPad и Android

1. Установите **WireGuard** из App Store или Google Play.
2. Нажмите **+** → **Create from file or archive** → выберите скачанный файл `.conf`.
3. Включите туннель.
