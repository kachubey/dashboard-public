You can add the configuration in three ways: **scan the QR code**, **copy the link** and paste it into the app, or **download the .txt** file and import it.

### Windows

1. Install **Hiddify** (<https://github.com/hiddify/hiddify-app/releases>) or **v2rayN** (<https://github.com/2dust/v2rayN/releases>).
2. Click **Show link** above → **Copy**.
3. In the app: **+** / **Add profile** → **Add from clipboard**.
4. Connect.

### macOS

1. Install **Hiddify** or **FoXray** / **V2Box** from the App Store.
2. Copy the link above and add it from the clipboard, then connect.

### iPhone and iPad

1. Install **Hiddify**, **Streisand** or **V2Box** from the App Store.
2. Tap **Show link** above, then either scan the QR code with the app from another screen, or **Copy** and add from clipboard.
3. Allow the app to add a VPN configuration when iOS asks, then connect.

### Android

1. Install **Hiddify** or **v2rayNG** (Google Play or GitHub).
2. Scan the QR code or add the copied link from the clipboard, then connect.

Never share your link — it works like a password. If it may have leaked, contact IT support to get a new one.
