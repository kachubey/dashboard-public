WireGuard is being retired. Use it only if IT asked you to.

### Windows and macOS

1. Install **WireGuard**: <https://www.wireguard.com/install/> (macOS: App Store).
2. Download your `.conf` file above.
3. In WireGuard: **Import tunnel(s) from file** → choose the file → **Activate**.

### iPhone, iPad and Android

1. Install **WireGuard** from the App Store or Google Play.
2. Tap **+** → **Create from file or archive** → choose the downloaded `.conf` file.
3. Turn the tunnel on.
