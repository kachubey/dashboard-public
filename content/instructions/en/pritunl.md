### Windows and macOS

1. Install **Pritunl Client**: <https://client.pritunl.com/#install>.
2. Download your configuration above (`.ovpn` file).
3. Open Pritunl Client → **Import** → choose the downloaded file.
4. Select the profile → **Connect**. Enter the PIN or one-time code if asked.

### iPhone and iPad

1. Install **OpenVPN Connect** from the App Store.
2. Download the `.ovpn` file on the phone and open it with **OpenVPN Connect** (Share → OpenVPN).
3. Tap **Add**, then turn the profile on.

### Android

1. Install **OpenVPN Connect** from Google Play.
2. Download the `.ovpn` file, open OpenVPN Connect → **+** → **Upload file** → choose it.
3. Tap **Add**, then turn the profile on.

If the connection fails, contact IT support and mention the name of the configuration.
